Part 2: How to get your Screenshot
To fulfill the visual part of your assignment:

In Visual Studio Code, save your file (Ctrl + S on Windows or Cmd + S on Mac).

Right-click anywhere inside the code editor and select Open with Live Server.

Your webpage will open in your default web browser. You will see the visual differences between the headings (h1 through h6), the horizontal lines (hr), the bold/italic text, and the line breaks (br).

📸 Take a screenshot of your entire browser window showing the rendered resume page.
