The HTML Code
Copy this updated structure into your HTML files. You will need to customize the <title> and content attributes to match the specific project you are updating.

HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <!-- 1. Character encoding -->
    <meta charset="UTF-8">
    
    <!-- 2. Mobile viewport tag for responsive design -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- 4. Meaningful meta description for SEO -->
    <meta name="description" content="This is an updated HTML project demonstrating proper page setup, metadata inclusion, and SEO best practices.">
    
    <!-- 3. Meaningful page title -->
    <title>Updated Project - Proper Metadata</title>
    
    <!-- 5. Favicon link -->
    <link rel="icon" href="images/favicon.ico" type="image/x-icon">
    
    <!-- 6. CSS stylesheet link (assuming a basic styles.css file exists) -->
    <link rel="stylesheet" href="css/styles.css">
</head>
<body>

    <header>
        <h1>Metadata & Page Setup Complete</h1>
        <p>This page is now optimized for mobile viewing, search engines, and browser tabs.</p>
    </header>

    <main>
        <section>
            <h2>Why Metadata Matters</h2>
            <p>The code in the <code>&lt;head&gt;</code> of this document ensures that special characters render correctly, the layout adapts to mobile phones, search engines understand the page content, and a custom icon appears in the browser tab.</p>
        </section>
    </main>

</body>
</html>
Setup and Submission Instructions
Set Up the Favicon:

Find a small image or icon (ideally square, like 32x32 pixels or 64x64 pixels).

Save it as favicon.ico or favicon.png.

Place it inside an images folder within your project directory. (If you use a .png file, update the HTML link code to <link rel="icon" href="images/favicon.png" type="image/png">).

Verify CSS and File Paths: Ensure that your stylesheet (if you have one) is correctly linked. The example code assumes a file named styles.css is located inside a css folder. If your files are in the same directory as the HTML file, just use href="styles.css".

Test in Browser: Double-click your HTML file to open it. Look closely at the top of your browser window (the tab bar). You should see your new <title> text and your custom favicon appearing right next to it.

Take a Screenshot: Take a screenshot of your entire browser window, making sure the browser tab containing the title and the favicon is clearly visible.

Submit: Upload your updated HTML files and the browser screenshot as required by your instructor.
